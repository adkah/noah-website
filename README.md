# Noah Achod Portfolio

The portfolio is a static [Astro](https://astro.build/) site deployed to GitHub Pages.

## Development

Requires Node.js 24 or later.

```sh
npm install
npm run dev
```

The development server is available at `http://localhost:4321`.

## Validation

```sh
npm run check
npm run build
```

Astro page files live in `src/pages`, shared UI in `src/components`, and static media in `public`.
